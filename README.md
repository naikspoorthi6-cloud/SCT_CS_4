# Task 04 – Keylogger Demonstration

## Project Overview
This project is a Python-based keylogger demonstration developed as part of the Cybersecurity Internship at SkillCraft Technology.

The application captures and records keyboard inputs entered within its own text box and saves the recorded keystrokes to a text file.

## Features
- Captures keyboard inputs within the application.
- Records individual keystrokes.
- Identifies special keys such as Enter, Backspace and Space.
- Displays the total number of recorded keystrokes.
- Saves recorded inputs into a `.txt` file.
- Provides a simple graphical user interface.

## Technologies Used
- Python 3
- Tkinter
- File Handling
- Event Handling

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/naikspoorthi6-cloud/SCT_CS_4.git
```

2. Open the project folder in VS Code.

3. Run the following command:

```bash
python keylogger.py
```

4. Type something in the application's text box.

5. Click **Save Keystrokes** to save the recorded input.

## Learning Outcomes
- Understanding keyboard event handling in Python.
- Working with Tkinter for GUI development.
- Learning Python lists and functions.
- Implementing file handling.
- Understanding the basic working principles of keyloggers.

## Ethical Considerations
This is an educational demonstration designed to capture keyboard inputs only within its own application window.

It does not monitor system-wide keyboard activity or collect input from other applications.
